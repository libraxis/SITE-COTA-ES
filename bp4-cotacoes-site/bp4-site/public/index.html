Conectar à API do Banco de Preços

Informe seu Token de Acesso API-Banco de Preços. O token fica somente no servidor desta sessão e não é enviado ao navegador para chamadas posteriores.

Só coloque a senha se você for o administrador. Se for usuário comum, deixe em branco e faça login somente com o token informado.
Nunca compartilhe seu token ou a senha de administrador em chats, repositórios ou código público.
MAPA DE FORNECEDORES

Fornecedores de licitações públicas

Pesquise o descritivo do item. O sistema procura resultados homologados, referências públicas de preço e, quando houver evidência pública disponível, empresas que apresentaram proposta, participaram ou foram classificadas no item/processo.

Fontes: PNCP + Compras.gov.br + fontes públicas do processo + dados cadastrais públicos de CNPJ. A pesquisa diferencia vencedor/homologado, proposta/participação e referência pública de preço. Propostas de participantes só são mostradas quando existe evidência pública identificável; a ausência de registro não significa que a empresa não participou.
Busca inteligente em andamento: consultando várias páginas do PNCP e Compras.gov.br, ampliando a amostra e procurando evidências públicas de propostas/participação. A pesquisa continua mesmo se uma fonte estiver instável...
