Conectar à API do Banco de Preços

Informe seu Token de Acesso API-Banco de Preços. O token fica somente no servidor desta sessão e não é enviado ao navegador para chamadas posteriores.

Só coloque a senha se você for o administrador. Se for usuário comum, deixe em branco e faça login somente com o token informado.
Nunca compartilhe seu token ou a senha de administrador em chats, repositórios ou código público.
MAPA DE FORNECEDORES

Fornecedores de licitações públicas

Pesquise o descritivo do item. O sistema usa busca inteligente, cache e consultas paralelas no PNCP e Compras.gov.br para ampliar a cobertura sem repetir consultas desnecessárias.

Fontes: PNCP + Compras.gov.br + dados cadastrais públicos de CNPJ. Para cada fornecedor com CNPJ, o sistema consulta contatos públicos com cache e processamento paralelo. O CNPJ Biz também fica disponível como fonte de conferência. Empresas que não possuem telefone/e-mail público continuam sendo identificadas como “NÃO LOCALIZADO”.
Busca inteligente em andamento: consultando PNCP e Compras.gov.br em paralelo, ampliando a amostra de licitações e fornecedores. A pesquisa continua mesmo se uma fonte estiver instável...
Contatos: aguardando os primeiros fornecedores...

ATA DE REGISTRO DE PREÇOS

Atas vigentes disponíveis para adesão

Pesquise um item e encontre atas vigentes com possibilidade de adesão. O sistema usa busca inteligente, consulta o detalhe oficial da ata e tenta enriquecer automaticamente o resultado com fornecedor, CNPJ e vigência.

Fontes: PNCP + Compras.gov.br. A tela prioriza atas vigentes com indicação explícita de “Permite Adesão”.
Busca inteligente em andamento: consultando atas vigentes em paralelo e enriquecendo os resultados com fornecedor, CNPJ, vigência e possibilidade de adesão...
